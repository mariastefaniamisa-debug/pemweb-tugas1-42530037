## Fitur

- Struktur HTML5 semantik: `header`, `nav`, `main`, `section`, `article`, `aside`, dan `footer`
- Navigasi satu halaman ke lima bagian: Tentang, Proyek, Keahlian, Sertifikasi, dan Kontak
- Bagian hero dengan foto profil dan dua tombol ajakan (Lihat proyek, Hubungi saya)
- Kartu proyek dengan CSS Grid: Landing Page Portofolio dan Simulasi Jaringan VLAN
- Daftar keahlian teknis dan catatan belajar (callout)
- Aksesibilitas: `lang="id"`, teks `alt` deskriptif pada setiap gambar, `aria-label` pada navigasi, dan `aria-labelledby` pada setiap section
- Tampilan responsif dengan meta viewport, Flexbox, Grid, dan variabel CSS
